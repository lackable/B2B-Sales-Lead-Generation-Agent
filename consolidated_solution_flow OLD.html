Multi-Agent System Architecture & Solution Process Flow

Shortlister Agent & LinkedIn Finder Agent · End-to-End Orchestration & Execution Pipeline

High Concurrency & Robustness

Shortlister Agent utilizes asyncio.Semaphore(5) for company data enrichment, while triggering parallel subprocess instances for per-company decision maker research without blocking the event loop.

Dual-Track Verification Engine

Company official LinkedIn URLs are verified first deterministically using headless Selenium homepage crawling, followed by an LLM web search sub-agent fallback when homepage links are unresolvable.

Multi-Turn MCP Tool Loop & Persistence

LinkedIn Finder Agent executes deep profile searches via Bright Data MCP and SerpAPI. Execution graph state is checkpointed into SQLite (memory.db) with exportable Excel workbooks.
