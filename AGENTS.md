# Agent Instructions

Project memory lives in docs/. Read docs/PROJECT_CONTEXT.md and docs/TASKS.md before exploring the repo.

- `docs/PROJECT_CONTEXT.md` — stable facts: repo map, architecture, runtime, conventions, constraints, verification commands
- `docs/TASKS.md` — what is active, blocked, and next
- `docs/DECISIONS.md` — ADRs (check before changing architecture or conventions)
- `docs/CHANGELOG_WORK.md` — what previous agents changed and how they verified it
- `docs/LEARNINGS.md` — known pitfalls, quirks, and pre-existing bugs

`README.md` remains the user-facing documentation.
