Multi-Agent System Architecture & Native Subgraph Flow

Shortlister Agent & LinkedIn Finder Subgraph · Native In-Process Multi-Agent LangGraph Pipeline

Native In-Process Subgraph Architecture

LinkedIn Finder Agent executes as a native compiled LangGraph Subgraph (contact_finder_graph). Shortlister Agent invokes it directly in-process via await run_linkedin_finder_subgraph(...), eliminating subprocess launching overhead.

Concurrent Dual-Task Agent Loop

For each candidate company, Shortlister Agent launches two concurrent in-process tasks: Task 1 verifies company LinkedIn URLs via Selenium/LLM search, while Task 2 executes the LinkedIn Finder Subgraph in parallel.

Multi-Turn MCP Tool Loop & Persistence

The Subgraph executes deep profile searches using Bright Data MCP and SerpAPI. Multi-agent state is check-pointed in SQLite (memory.db), generating styled Excel workbooks & JSON logs.
